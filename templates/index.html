How it works

1

TextVectorization

Raw text → 200 word ids (10k vocab, from train set only)

2

Embedding

Each word id → 64-dim vector (mask_zero for padding)

3

Bidirectional LSTM

64 LSTM units read the review forward & backward, with dropout + SpatialDropout1D

4

Dense + Sigmoid

L2-regularized dense layer → one probability between 0 and 1

Built from “IMDB Review Classification With LSTM.ipynb” · 20k review sample · Early stopping restores best weights
